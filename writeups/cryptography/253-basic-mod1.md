## Résolution

Méthode : **mod 37 + charset**.

Chaque nombre modulo 37 : 0-25 -> A-Z, 26-35 -> chiffres, 36 -> `_`. Concatener puis envelopper dans le format du flag.

## Flag

```
academy{R0UND_N_R0UND_81CE8A51}
```
