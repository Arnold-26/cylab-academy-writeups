## Résolution

Méthode : **cipher cyclique + selfinput cubique**.

Deux couches. 1) Inverser `convert.py` : le chiffrement fait `lookup2[(lookup1.index(c) - prev) % 40]` ; pour déchiffrer on calcule `cur = (prev + lookup2.index(ch)) % 40` puis `lookup1[cur]`. On obtient un script Python 2 selfinput. 2) Ce script imprime les caractères aux indices cubiques (1, 8, 27, 64...) de lui-même. On applique la même regle au texte.
