# 2warm

**Catégorie** : Général Skills · **Difficulté** : Easy · **Épreuve** : picoCTF 2019
**Challenge** : #86

## Énoncé

> Can you convert the number 42 (base 10) to binary (base 2)?

**Entrée** : —

## Résolution

`bin(42)` → `0b101010` → on retire le préfixe : **101010**.

## Flag

```
academy{101010}
```

## Ce qu'il faut retenir

Attention : le format attendu ne contient pas le préfixe `0b`.
