# asm2

## Énoncé

> What does asm2(0x4,0x1f) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/5ec32e278f00879ac28fb9cf32d29244691a853a31841547ec65e852209b4de2/test.S)

## Résolution

Méthode : **boucle additive**.

`asm2(0x4,0x1f)` : compteur initial 0x1f, boucle tant que i <= 0x3ae2 avec i += 0xf2. Il faut 63 iterations (4 + 242*63 > 15074), donc 31 + 63 = 94 = 0x5e.

## Flag

```
0x5e
```
