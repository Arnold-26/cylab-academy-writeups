# solve/ - solution scripts

One folder per challenge (`solve/<id>/`) with the script that produced the flag, followed by the
helper modules and data files it actually reads. Everything else (intermediate attempts,
measurement tools, throwaway probes) is kept in `solve/<id>/archive/` so the reasoning is still
there without drowning the deliverable.

- 163 folders, 191 visible files, 1694 archived variants
- every script carries a standard header: challenge, category, event, flag, write-up link, usage
- the seven hardest (55, 136, 302, 441, 478, 495, 496) are annotated step by step

IDs map to [`INDEX.md`](../INDEX.md). Each writeup ends with a `## Scripts` section pointing to
its folder.
